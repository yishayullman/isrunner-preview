# תאימות ל-Cloudflare Workers + D1 ונתיב חזרה בטוח (Rollback)

## עקרונות שנשמרו
1. **אפס נגיעה בייצור:** הפיתוח והבדיקות רצים על בסיס נתונים מקומי (`SQLite` באמצעות `node:sqlite`) בלבד. לא בוצעה העלאה לאוויר ולא הורצה מיגרציה על D1 חי.
2. **תאימות SQL מלאה ל-D1:**
   - קובץ הסכמה [`migrations/0001_initial.sql`](../migrations/0001_initial.sql) משתמש אך ורק בטיפוסי SQLite התקניים הנתמכים ב-Cloudflare D1 (`TEXT`, `INTEGER`, `REAL`, `CHECK`, `UNIQUE`, אינדקסים ומפתחות זרים).
   - כל התאריכים נשמרים כמחרוזות ISO-8601 UTC (`TEXT`).
3. **תאימות האש סיסמאות:**
   - PBKDF2-SHA256 עם 100,000 איטרציות וסולט ייחודי לכל משתמש — זהה למה שמקובל ב-Cloudflare Workers WebCrypto, כך שניתן לשמור על תאימות למשתמשים קיימים (לאחר אימות פורמט המחרוזת הקיים בייצור לפני כל מיגרציה!).
4. **שמירה על ריצות קיימות:**
   - ריצות קיימות מסומנות מפורשות `source_type = 'self_reported_legacy'` ו-`source_verified = 0` ("דיווח עצמי, לא מאומת") ואינן נמחקות או מומרות בשקט.
   - `notifications_dispatched = 1` עבור ריצות היסטוריות כדי שלא יישלחו התראות על ריצות ישנות.
5. **דרך חזרה (Rollback):**
   - לפני כל מיגרציה עתידית על D1 חי (רק לאחר אישור מפורש שלך):
     1. לבצע גיבוי מלא של D1 (`wrangler d1 export <db> --remote --output backup-YYYY-MM-DD.sql`).
     2. להריץ מיגרציות תוספתיות בלבד (`ADD COLUMN` / `CREATE TABLE IF NOT EXISTS`) ללא `DROP` או `DELETE` של נתוני אמת.
     3. לשמור את גרסת ה-Worker הקודמת זמינה ל-`wrangler rollback` מיידי במקרה הצורך.
